# ABAI · ИС ЦД Актива — мокап портала (React) · версия 2.1

Кликабельный мокап информационной системы «Цифровой двойник актива» на базе продуктов ABAI (АО НК «КазМунайГаз», Upstream).
Только фронтенд на демонстрационных данных: **React 19 + MUI 7 + MUI X DataGrid 8 + Recharts 3**, сборка Vite, `HashRouter`, `base: './'`.

Процессы, шаги, исполнители (дорожки), системы, документы, развилки и слияния — из итогового архива BPMN **Dream TO BE**
(целевой вариант на ABAI); показатели и объекты — условные, но согласованные между экранами (единый сюжетный набор данных).

Аудит предыдущей версии и концепция текущей — в `AUDIT.md`; статус версий 2.0 и 2.1 — в `AUDIT.md` §5.

## Принципы

- **Задача первична.** Вход любой роли — «Ждёт моего решения» (просрочено · сегодня · на неделе). Задача открывает форму
  конкретного шага конкретного процесса с данными объекта и результатами предыдущих шагов.
- **Объект — точка входа.** Скважина, суточная сводка, программа ГТМ, элемент заводнения, трубопровод, бригады ВСР
  показывают свои процессы, задачи, документы и историю; из задачи — в объект, из объекта — в задачу.
- **Один набор данных.** Сюжетные объекты (`src/data/story.js`) одинаковы на всех экранах; реестр записей процессов
  не зависит от роли — роль только фильтр.
- **Исполнение по BPMN.** Несколько активных шагов (параллельные ветви), условные развилки по решению в форме,
  слияния ждут все ветви, адресный возврат на доработку с замечанием, нормативные сроки шагов, просрочки.
- **Предметный язык.** Записи процессов называются заявкой, сводкой, карточкой отклонения, программой …; слово «экземпляр»,
  коды BPMN и источники видны только при включённом переключателе «Демо · BPMN».

## Устройство

- **Вход по ролям** — 9 ролей по дорожкам BPMN: КМГ, КМГИ, ОМГ · ДДНГ, ОМГ · геология и разработка, КазНИПИ,
  ОМГ · бурение и ВСР, ЦИТС НГДУ, подрядная организация (ограниченный доступ, отдельное меню), администратор данных.
- **Меню — только модули:** рабочий стол (главная, мои задачи), ЦД скважины, ЦД пласта, ЦД добычи, единые данные, аналитика.
  У подрядчика: главная, мои задачи, мои объекты, о системе.
- **Главная** — рабочий стол роли: ждёт моего решения → показатели роли → объекты и отклонения роли (или очередь экспертиз)
  → события; состояние двойников — у ДДНГ, КМГИ и администратора.
- **Мои задачи** — активные шаги на дорожках роли по срочности, возвращённые на доработку, выполненные с результатом.
- **Модуль** (`/m/<skv|plast|dob|data>`): «Обзор» (состояние двойника: объекты, отклонения, модели, ход исполнения) ·
  «Процессы» · «Задачи» · объекты (фонд скважин и паспорт; карта пласта; объекты добычи; единая база и интеграции КХД).
  Карточка объекта — `/m/<модуль>/obj/<id>`, в паспорте скважины — вкладка «Процессы и задачи».
- **Процесс** (`/m/<модуль>/p/<код>`): «Рабочее место» (экран ABAI процесса; очередь заявок Д6 строится из записей процесса) ·
  «Ход исполнения» · «Регламент процесса». «Запустить процесс» — для роли первого шага, с выбором объекта.
- **Запись процесса** (`…/run/<id>?step=<i>`): ход по шагам с ветвями (пройдено · сейчас · ждёт слияния · далее), форма шага,
  контекст объекта (отклонения, другие процессы по объекту), журнал. Действия: выполнить (с решением на развилке и ЭЦП),
  вернуть на доработку (адресно, с замечанием), в демо — делегировать и «Войти как …».

Формы шагов (версия 2.1): специальные формы у всех 553 шагов 24 процессов. Спецификации разделены по частям ЦД:
`specs.jsx` (Д1, Д2, Д6, Д9, Б3, Б4, Б5, Р2, Р4, Г3.4), `specs.dob.jsx` (Д3, Д4, Д5, Д7, Д8), `specs.plast.jsx` (Р1, Р3, Б1, Б2),
`specs.geo.jsx` (Г1, Г3), `specs.seis.jsx` (Г3.1, Г3.2, Г3.3); общие помощники — `kit.js`. Решения на развилках — подписи ветвей BPMN,
документы — из шага BPMN. Виджеты форм (`widgets*.jsx`) и рабочие места читают одни модули данных (`*.data.js(x)` рядом с рабочим
местом), поэтому цифры совпадают на главной, в обзоре модуля, рабочем месте, карточке объекта и форме шага.

Рабочие места связаны с записями процессов: действие, которое в BPMN является шагом (согласовать программу ГТМ, направить план
надёжности, сформировать программу энергоэффективности, пересчитать ИМА …), выполняется в форме шага; рабочее место показывает
состояние записи и ведёт в шаг («Выполнить шаг в процессе» — если шаг на дорожке роли, иначе «Открыть в процессе»).

Карточки объектов показывают предметный виджет по виду объекта (трубопровод — риск и матрица, энергопотребление, потенциал, ИМА,
мероприятие, профиль, модель, куст, участок недр — карта и рейтинг секторов, сейсморазведка — ход съёмки), паспорт скважины —
плашку «По скважине идёт …». Поиск охватывает задачи, скважины, объекты, записи, отклонения и документы.

Пробелы модели BPMN не исправляются, а показываются в «Регламенте процесса» при включённом демо: шаги без исходящего или входящего
перехода и взаимные переходы без условия выхода (такой цикл движок проходит один раз).

## Разработка

```
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # просмотр сборки
node ../_t/v21/formcheck.mjs [Д3 …]   # проверка форм всех шагов без браузера: решения ↔ ветви BPMN, undefined/NaN, виджеты
node tools/gen_bpmn.cjs   # обновить src/data/bpmn.js из соседнего abai-mockup (шаги, развилки, аннотации)
```

Открывать нужно через сервер (`npm run preview`), а не двойным щелчком по файлу: браузер не загружает модули с `file://`.
Состояние демонстрации (роль, выполненные шаги, прочитанные уведомления) хранится в `localStorage`; сброс — в меню роли при включённом демо-режиме.

Сборка: основной чанк ~130 КБ; React, MUI, DataGrid, Recharts, данные BPMN, запись процесса с формами и рабочие места — отдельными
чанками (`vite.config.js`, `codeSplitting.groups`). Экраны по требованию после входа предзагружаются в простое браузера (`src/lib/lazyp.jsx`),
поэтому переход на рабочее место идёт без заглушки. Адаптивность: запись процесса — 3 колонки от 1536 px, 2 — от 900 px, 1 — ниже;
боковое меню ниже 1200 px сворачивается до иконок, поиск — в кнопку.

src/data/story.js              сюжетный набор: объекты, скважины-герои, отклонения, записи процессов, предметные имена, нормативы сроков
src/data/core.js               роли, ДЗО, фонд скважин (с героями), ряды добычи, отклонения, двойники

src/pages/Home.jsx, Tasks.jsx  рабочий стол роли, мои задачи

src/pages/*/*.data.js(x)       общие данные рабочих мест и форм: gno, pipe, energy, pot, ima, profile (dob); dev, geo, seis (plast); drill, well (skv)
